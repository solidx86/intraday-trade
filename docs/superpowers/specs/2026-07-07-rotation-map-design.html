Rotation Map — qualitative destination read for the Pre-Market Briefing

Date: 2026-07-07  ·  Skill: premarket-briefing-skill  ·  Branch: feat/premarket-rotation-map

Approved design — ready for implementation plan

Problem

The briefing is excellent at naming what is breaking and why (the macro cause and the weak sector) but structurally blind to where the money is going — the destination of a rotation. Section 1.1 reports sector leadership as a single Sector tape: [leader] lead · [laggard] lag pair drawn from the eleven broad GICS SPDRs, and nothing synthesises the handoff.

Concretely: for the week into 2026-07-02 the briefings nailed the semis/memory breakdown and the weak-labour → rate-cut pivot, but on 2026-07-02 the sector line read "XLK lead · XLV lag — tech leading" and stopped there — while beneath that bounce, rate-cut beneficiaries (homebuilders, small-caps, biotech innovators) were already taking leadership. The defensive-leadership rotation the trader cared about was invisible.

Two root causes:

  • The tape is too coarse. Rotation shows up first in sub-industry and factor ETFs (semis vs tech, biotech vs pharma, homebuilders, small-caps, min-vol), not the eleven broad sectors.
  • The watchlist is tech-tilted. Destination leadership emerging outside it (off-price retail, cruise, biotech) can't surface through the per-ticker scan — so widening the tape (unbiased, free — one batched call) is the fix, not widening the watchlist.

There is also a data hazard the design must respect: sector/factor ETF pre-market prints are thin or absent, so ranking them on this-morning gaps (when they exist) against yesterday's closes (when they don't) is an apples-to-oranges error that produces a wrong destination call — worse than none.

Goals

  • Add a qualitative Rotation Map to section 1.1 that names the groups money is leaving and entering — the Tier-2 (industry) destination read — plus a regime-divergence flag. No raw percentages in the body, so the number-provenance hook is untouched.
  • Widen the tape with sub-industry + factor ETFs so the destination is visible at all.
  • Rank on a uniform completed-session basis so the call is correct by construction, not corrupted by thin pre-market prints.
  • Measure rotation as dispersion around SPY, so it stays correct on broad up/down days (who truly leads, not merely who is green).
  • Keep the change additive and format-consistent; ship the smallest thing that catches the destination.

Background — the read (one screen)

This is Tier 2 of the standard top-down funnel (macro → industry → company). Rotation is a multi-session, full-volume, close-to-close flow phenomenon — not an overnight gap. So the map reads the last completed regular session, and it measures each group relative to SPY (rotation = dispersion around the index). Pre-market is the wrong input: thin ETF liquidity makes it noise, and overnight index beta compresses the very dispersion the map exists to measure.

The one place today's pre-market does belong is the regime check: the freshly-classified dollar/yields regime (already computed in 1.1) sets an expected leadership; when the standing prior-close rotation contradicts it, that divergence is the signal — e.g. a dovish GOLDILOCKS tape that "should" lift QQQ + cyclicals while defensives quietly lead = a growth-scare undertone under a relief bounce. The block is deliberately mixed-basis: prior-close rotation vs today-pre-market regime, and the contrast is the value.

Design

A. Data layer — scripts/fetch_market_data.py

A1. Widen TAPE_SYMBOLS with twelve symbols (all plain US ETFs → resolve AAPL-style; verified once against the live CNBC endpoint per the file's existing note — any that don't resolve emit N/A, non-blocking):

  • Sub-industry — SMH, XBI, KRE, XRT, XHB, PEJ, JETS
  • Factor / breadth — RSP, IWM, USMV, MTUM
  • Benchmark — SPY

A2. Capture the completed-session move on every row. Today the PRE_MKT branch overwrites chg_pct with the pre-market move and drops the regular-session number. Add to both branches, so every symbol carries a uniform prior-close basis:

row["reg_last"]    = _to_float(q.get("last"))        # last completed session close
row["reg_chg_pct"] = _to_float(q.get("change_pct"))  # that session's % — uniform across all symbols

chg_pct still carries today's pre-market for the existing Sector tape: line. Add reg_chg_pct to the printed-ledger columns so the model can read it for the ranking. Verify validate_quote_ledger.py, validate_quote_hook.py and pytest don't pin an exact ledger column-set (if they do, extend the fixture — no logic change).

B. Compute layer — model-driven in SKILL.md

The script supplies data only; the ranking / gating / divergence logic lives in SKILL.md as instructions the model applies when composing 1.1 — mirroring how the existing sector leader/laggard line is already model-derived from ledger rows. Because v1 emits no numbers, there is no fabrication risk to guard against; a deterministic scoring script is deferred to a follow-up.

  • Ranking: for each rotation-tape ETF, rel = reg_chg_pct − SPY.reg_chg_pct. INTO = groups with rel ≥ +T; OUT = rel ≤ −T; collapse when nothing clears the band.
  • Materiality band T lives in data/framework/framework-full.md (private), referenced opaquely from public SKILL.md.
  • ETF → group labels (descriptive, public): SMH=semis, XBI=biotech, XHB=homebuilders, KRE=regional banks, XRT=retail, PEJ=leisure/restaurants/cruise, JETS=airlines, RSP=equal-weight/breadth, IWM=small-caps, USMV=min-vol/defensive, MTUM=momentum.
  • Regime divergence reuses references/cross-asset-matrix.md's per-regime expected leadership. A small enrichment pass gives every regime token (SCARED / GREEDY / GOLDILOCKS / NEUTRAL + REFLATION) an explicit expected-leaders / laggards row. The flag fires when standing INTO groups sit in the regime's expected-laggard set (or vice-versa).

C. Render layer — the 1.1 block

Directly under the existing **Sector tape:** line, always present, two bold lines:

**Rotation map (prior close):** OUT → [lagging groups] · INTO → [leading groups] — [money leaving <X> is landing in <Y>]
**Regime check:** [today pre-mkt regime] expects [expected leaders]; standing rotation [confirms / diverges] — [flag or "no divergence"]

Quiet-tape collapse (nothing clears the SPY-relative band):

**Rotation map (prior close):** no material rotation — leadership broad, dispersion inside the band.
**Regime check:** [regime] broadly aligned; no divergence flag.

(prior close) here is a basis note — the whole block reads yesterday's session, distinct from the pre-market Sector tape: line above it. The lines carry group names, no $/%, so the number-tag hook never fires on them.

Worked example — a 2026-07-02-type tape
Rotation map (prior close): OUT → semis, neocloud · INTO → homebuilders, small-caps, biotech — money leaving semis is landing in rate-cut beneficiaries.
Regime check: GOLDILOCKS expects QQQ + cyclicals to lead; standing rotation diverges — defensives leading under a dovish tape = growth-scare undertone.

D. Testing, hygiene, rollout

  • Tests: pytest -q stays green; extend the ledger fixture only if a column-set assertion trips. Add a validator presence-check for the two new 1.1 lines (mirroring the existing tape-line checks) so CI guards the format, proven by a negative unit test.
  • Hygiene (leak test): the threshold T → private framework; everything else (symbols, plumbing, block format, group labels, rank-vs-SPY method) is generic market structure → public.
  • Rollout: one live fetch to confirm the twelve symbols resolve; regenerate the next session's briefing and eyeball the map; no hook change (no body numbers).
